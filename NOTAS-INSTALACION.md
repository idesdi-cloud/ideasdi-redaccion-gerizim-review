# Instalación · ideasDi Redacción Gerizim v0.4.0-RC1.4

1. Instalar el ZIP desde WordPress.
2. Activar el plugin.
3. Verificar la versión **0.4.0-RC1.4**.
4. Ir a **Gerizim → Reglas editoriales**.
5. Exportar las reglas actuales como respaldo antes de hacer ajustes.
6. Probar un artículo nuevo y descargar el reporte completo.

Las reglas editoriales editables se guardan en la base de datos de WordPress. No se modifican archivos físicos del plugin desde el dashboard.
